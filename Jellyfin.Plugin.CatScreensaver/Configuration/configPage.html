Cat Screensaver

When the Jellyfin web interface stays idle, the screen fades to black and one or more original cats walk, sit, groom and fall asleep. Any key, click or movement wakes it.

File Transformation is not registered.
Install IAmParadox27/jellyfin-plugin-file-transformation and restart Jellyfin. Without it the script is not added to jellyfin-web. As a manual fallback, use a JavaScript injector plugin with <script src="/CatScreensaver/cat-screensaver.js" defer></script>.

Set Jellyfin's own screensaver (Dashboard → Display) to None, otherwise both overlays can compete.

Palettes

Assigned to cats in this order. If no palette is selected, orange is used.

Behavior

Video playback always blocks it.

Preview uses the saved settings. Press any key or click anywhere to close it.
